# Khushi Parmar — Portfolio

Personal portfolio site for [Khushi Parmar](https://github.com/khushi491), a software engineer in New York focused on backend systems, full-stack products, and applied AI.

## Stack

- Next.js (App Router) and TypeScript
- Tailwind CSS
- Deployed on Vercel (project name: `khushiparmar`)

## Local development

```bash
npm install
npm run dev
```

## Content notes

Copy is sourced from Khushi’s résumé and from project READMEs / live demos that were checked. Unsourced metrics and certifications from an earlier portfolio are not included. The résumé PDF in `public/` is the V source-of-truth file, renamed for a clean download URL.
